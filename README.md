# 💻 Marquei — Interface Frontend

Interface web do sistema **Marquei**, ERP simples e intuitivo para barbearias, salões de beleza e clínicas de estética.

## 🛠️ Tecnologias
- **Linguagem:** Python
- **Interface:** Streamlit

## 📌 Principais Telas
- **Agenda:** Agendamento flexível com múltiplos itens (produtos e serviços) por cliente.
- **Clientes & Profissionais:** Cadastro e histórico de atendimentos.
- **Estoque & Caixa:** Vendas de balcão e controle de lançamentos.
